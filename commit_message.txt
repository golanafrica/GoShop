feat(security): v4.4.21 - Rate Limiting sur l'authentification (Login)

Implémentation d'un système de rate limiting pour prévenir les attaques par force brute sur le endpoint /login.

Fonctionnalités ajoutées :
1. Interface LoginRateLimiter (domain/service)
2. Implémentation Redis avec fallback mémoire (infrastructure/rate_limit)
   - Limite par email : 5 tentatives / 15 min
   - Limite par IP : 20 tentatives / 15 min
   - Réinitialisation automatique après une connexion réussie
3. Intégration dans LoginUsecase.ExecuteWithContext
4. Nouvelle erreur utils.ErrTooManyAttempts (HTTP 429)
5. Mise à jour des tests unitaires (mocks + cas de test rate limit)

Comportement :
- Si Redis est disponible, utilise Redis pour un rate limit distribué.
- Si Redis est indisponible, fallback automatique sur un rate limiter en mémoire (thread-safe).
- Les tentatives échouées (user not found, invalid password, locked, inactive) incrémentent le compteur.
- Une connexion réussie réinitialise les compteurs pour cet email/IP.

Couverture de test maintenue à 91.0% sur user_usecase.
