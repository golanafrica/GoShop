feat(security): v4.4.2 - Session Management complet

Objectif :
  Implementer la gestion des sessions utilisateurs pour permettre :
  - Creation automatique de session au login
  - Verification de session active a chaque requete
  - Revocation de session au logout
  - Rejet immediat des sessions revoquees
  - Audit trail complet (IP, User Agent, device)

Architecture :
  - Migration 025 + 025b : Table user_sessions (12 colonnes)
  - Entite UserSession : Hash SHA-256, DeviceInfo, statuts dynamiques
  - Repository : 25 methodes (CRUD, securite, nettoyage, stats)
  - 5 Usecases : list, revoke, revoke-all, stats, cleanup
  - Handler HTTP : 5 endpoints REST
  - Middleware Auth : Verification session a chaque requete

Endpoints ajoutes :
  - GET    /api/admin/sessions         - Lister sessions
  - GET    /api/admin/sessions/stats   - Statistiques globales
  - POST   /api/admin/sessions/revoke  - Revoquer une session
  - POST   /api/admin/sessions/revoke-all - Revoquer toutes
  - POST   /api/admin/sessions/cleanup - Nettoyage (super_admin)
  - POST   /logout                     - Deconnexion utilisateur

Securite :
  - Token JWT avec jti (session_id)
  - Hash SHA-256 du token en base (jamais en clair)
  - Verification middleware a chaque requete protegee
  - Revocation immediate au logout
  - Rejet 401 des sessions revoquees
  - Audit trail (IP, User Agent, device info)
  - Expiration automatique (7 jours par defaut)

Parsing User Agent :
  - Navigateurs : Chrome, Firefox, Safari, Edge, IE, Opera
  - OS : Windows, macOS, Linux, Android, iOS
  - Devices : Desktop, Mobile, Tablet

Statistiques :
  - Total sessions actives/revoquees/expirees
  - Users uniques actifs
  - Moyenne d'inactivite
  - Top 10 users les plus actifs

Tests valides (6/6) :
  1. Login : OK (session creee avec jti)
  2. /auth/me (session active) : OK (200)
  3. Lister sessions : OK (1 session [CURRENT])
  4. Statistiques : OK (1 active, 0 revoquee)
  5. Logout : OK (session revoquee)
  6. /auth/me apres logout : OK (401 Unauthorized)

Performance :
  - Login : ~1180ms (creation session inclus)
  - /auth/me : ~182ms (verification session)
  - Lister sessions : ~784ms
  - Stats : ~216ms
  - Logout : ~408ms (revocation session)
  - Rejet session revoquee : ~2.5ms

Impact :
  - Aucune breaking change
  - Middleware retro-compatible (SessionRepo optionnel)
  - Compatible avec v4.4.1 (migration additive)

Prochaine etape : Phase 4.3 (API Keys - optionnel)
