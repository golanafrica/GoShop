feat(security): v4.4.3 - API Keys Management complet

Objectif :
  Permettre l'acces programmatique a l'API via des cles API
  securisees avec scopes granulaires et audit trail.

Architecture :
  - Migrations 026 + 026b + 026c : Tables api_keys + api_key_usage_logs
  - Entite APIKey : Hash SHA-256, scopes, generation crypto/rand
  - Repository : 30 methodes (CRUD, securite, audit, stats)
  - 6 Usecases : create, list, revoke, revoke-all, stats, validate
  - Handler HTTP : 5 endpoints REST admin
  - Middleware APIKeyAuth : Authentification par cle API

Endpoints admin (JWT + RBAC) :
  - POST   /api/admin/api-keys           - Creer une cle
  - GET    /api/admin/api-keys           - Lister les cles
  - POST   /api/admin/api-keys/revoke    - Revoquer une cle
  - POST   /api/admin/api-keys/revoke-all - Revoquer toutes
  - GET    /api/admin/api-keys/stats     - Statistiques

Endpoints publics (API Key Auth) :
  - GET    /v1/public/products           - Scope: read:products
  - GET    /v1/public/shops              - Scope: read:shops

Securite :
  - Cles API prefixees (gsk_live_, gsk_test_)
  - Hash SHA-256 en base (jamais stockees en clair)
  - Affichage complet UNE SEULE FOIS a la creation
  - 18 scopes granulaires (read/write par domaine)
  - Revocation immediate avec HTTP 410 Gone
  - Rate limiting configurable (60/min, 10000/jour)
  - Limite 10 cles actives par utilisateur
  - Audit trail complet (usage logs)
  - Expiration configurable (defaut 1 an, max 5 ans)
